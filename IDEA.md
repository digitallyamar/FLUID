# Flexible UI Displays

## What is FLUID?
 FLUID stands for "Flexible UI Displays". It is a frontend library of html UI components that one can use to build beautiful and elegant web apps.

## What is the core idea of FLUID?

In the beginning of the internet, most of the web pages were built using simple HTML tags. As time progressed we introduced CSS to make the HTML elements look aesthetically pleasing. Soon it was followed by the inclusion of Javascript for making dynamic web elements. With these 3 things in place, people started building various UI libraries that later matured into full stack libraries such as REACT, Vue, Angular, Nextjs etc.

Now with AI assited coding, I believe it is time for us to build a new "FLUID" library that can be used by AI coding agents to beautiful and elegant websites that are even more dynamic and interactive.
